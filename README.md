# 平面図描画アプリ

タブレット対応の家の平面図描画アプリケーションです。フリーハンド描画をその場で整形する機能を持ちます。

## 📖 ドキュメント

- **[🚀 クイックスタートガイド](./QUICK_START.md)** - 5分で始める基本操作
- **[📚 ユーザーマニュアル](./USER_MANUAL.md)** - 詳細な機能説明
- **[🔧 技術仕様書](./TECHNICAL_SPECS.md)** - 開発者向け技術情報

## 特徴

- 🖊️ **フリーハンド描画**: タッチペンやマウスでの自由な描画
- 🔧 **図形認識**: フリーハンドの線を直線、円、四角形に自動変換
- 📱 **タブレット対応**: iPadやAndroidタブレットで快適に使用可能
- ⚡ **PWA対応**: アプリのようにインストールして使用可能
- 🎨 **カスタマイズ**: 線の太さや色を自由に変更
- ↩️ **アンドゥ/リドゥ**: 操作の取り消しとやり直し機能
- 📝 **テキスト機能**: 横書き・縦書きテキストの挿入
- 🚪 **建築要素**: 扉、階段、開口部の専用ツール
- 🗑️ **精密削除**: 線分単位での部分消去機能
- 📋 **定型文機能**: よく使用する文字列をプリセットから選択
- 🔗 **連続直線描画**: 一筆書きで連続する直線を描画

## 使い方

1. **描画ツールの選択**: ツールバーからペン、直線、連続直線、四角形、円、テキストを選択
2. **フリーハンド描画**: ペンツールで自由に描画（自動で図形認識）
3. **グリッド直線描画**: 直線ツールで正確な図形を描画（自動でグリッドにスナップ）
4. **連続直線描画**: 連続直線ツール（🔗）で一筆書きの直線を描画（0.5グリッド間隔でスナップ）
5. **水平・垂直線**: 直線ツール + Shiftキーで完全に水平・垂直な線
6. **テキスト入力**: テキストツールでクリックして文字を入力
7. **定型文入力**: 定型文ドロップダウンからよく使う文字列を選択
8. **部分消去**: 消しゴムツールで線の一部を削除
9. **スタイル調整**: 線の太さ、色、フォントサイズを調整
10. **操作管理**: クリア、アンドゥ（Ctrl+Z）、リドゥ（Ctrl+Y）で描画を管理

## 連続直線機能

**🔗 連続直線ツール**の使い方：
- **開始**: 連続直線ツールを選択してキャンバスをクリック
- **継続**: 次の点をクリックして線を延長
- **終了**: ダブルクリックまたは他のツールを選択
- **グリッドスナップ**: 0.5グリッド間隔（40px）で自動的にスナップ
- **用途**: 建物の外観や部屋の仕切りなど、連続する直線の描画に最適

## テキスト機能

### 通常のテキスト入力
- **横書きテキスト**: 🔤ボタンで一般的な横書きテキスト（左揃え）
- **縦書きテキスト**: 📝ボタンで日本語の縦書きテキスト（中央揃え）
- **フォントサイズ**: スライダーで12px〜48pxまで調整可能（標準48px）
- **入力方法**: テキストツール選択後、キャンバスをクリックして入力
- **確定**: Ctrl+Enterまたはテキストボックス外をクリック
- **キャンセル**: Escapeキーで入力をキャンセル

### 定型文機能
- **📋 定型文ドロップダウン**: よく使用する建築用語をカテゴリ別に整理
- **カテゴリ**: 
  - **部屋**: リビング、キッチン、寝室、トイレなど
  - **設備**: 洗面台、浴槽、階段、玄関など
  - **機器**: エアコン、冷蔵庫、洗濯機など
  - **寸法**: 畳数や一般的な寸法表記
- **配置**: 選択した文字は48pxサイズで中央揃えで配置
- **使用方法**: ドロップダウンから選択すると自動的にキャンバス中央に配置

## 消しゴム機能

**🗑️ 精密消しゴム**の特徴：
- **部分消去**: 線の一部分のみを削除可能
- **最小長保持**: 線が短くなりすぎないよう自動調整
- **アンドゥ対応**: 消しゴム操作も元に戻すことが可能
- **使用方法**: 消しゴムツールを選択して削除したい部分をドラッグ

## グリッド機能

- **自動スナップ**: 直線・四角形・円ツールは自動的に1グリッド（80px）間隔でスナップ
- **連続直線スナップ**: 連続直線ツールは0.5グリッド（40px）間隔でスナップ
- **20px間隔**: 細かい位置調整に便利
- **100px間隔**: 大きな区画の配置に便利
- **表示切り替え**: ⊞ボタンでグリッドのON/OFF

## キーボードショートカット

- **Ctrl + Z**: アンドゥ（操作を取り消し）
- **Ctrl + Y**: リドゥ（操作をやり直し）
- **Shift + 直線ツール**: 水平・垂直線を描画
- **Shift + ペンツール**: フリーハンドでもグリッドにスナップ
- **Ctrl + Enter**: テキスト入力確定
- **Escape**: テキスト入力キャンセル
- **ダブルクリック**: 連続直線描画終了

## 図形認識機能

フリーハンドで描画した線は自動的に以下の図形に変換されます：

- **直線**: まっすぐな線として認識
- **円**: 閉じた曲線として認識  
- **四角形**: 4つの角を持つ図形として認識

## デプロイ

### GitHub Pages（自動デプロイ）

このプロジェクトはGitHub Actionsを使用してGitHub Pagesに自動デプロイされます。

1. **GitHubにプッシュ**: mainブランチにプッシュすると自動でビルド・デプロイ
2. **GitHub Pages設定**: リポジトリ設定 → Pages → Source: GitHub Actions
3. **アクセス**: `https://yourusername.github.io/heimenzukei/`

### 手動デプロイ

他のホスティングサービスを使用する場合：

```bash
# ビルド
npm run build

# distフォルダの内容をホスティングサービスにアップロード
```

**対応ホスティング:**
- **Netlify**: ドラッグ&ドロップで即座にデプロイ
- **Vercel**: GitHub連携で自動デプロイ
- **Firebase Hosting**: `firebase deploy`でデプロイ
- **Surge.sh**: `surge dist/`でデプロイ

### PWAとしてインストール

デプロイ後、ユーザーは以下の方法でアプリをインストールできます：

**iPad/iPhone:**
1. Safariでサイトにアクセス
2. 共有ボタン（📤）をタップ
3. 「ホーム画面に追加」を選択

**Android:**
1. Chromeでサイトにアクセス
2. 「ホーム画面に追加」プロンプトが表示
3. 「追加」をタップ

**デスクトップ:**
1. Chrome/Edgeでサイトにアクセス
2. アドレスバーの「インストール」アイコンをクリック
