# 平面図描画アプリ

タブレット対応の家の平面図描画アプリケーションです。フリーハンド描画をその場で整形する機能を持ちます。

## 特徴

- 🖊️ **フリーハンド描画**: タッチペンやマウスでの自由な描画
- 🔧 **図形認識**: フリーハンドの線を直線、円、四角形に自動変換
- 📱 **タブレット対応**: iPadやAndroidタブレットで快適に使用可能
- ⚡ **PWA対応**: アプリのようにインストールして使用可能
- 🎨 **カスタマイズ**: 線の太さや色を自由に変更
- ↩️ **アンドゥ/リドゥ**: 操作の取り消しとやり直し機能
- 📝 **テキスト機能**: 横書き・縦書きテキストの挿入

## 使用技術

- **Vite** - 高速な開発とビルド
- **Vanilla JavaScript** - 軽量で高速
- **HTML5 Canvas** - 高性能な描画機能
- **PWA** - アプリライクな体験
- **レスポンシブデザイン** - 様々なデバイスに対応

## 使い方

1. **描画ツールの選択**: ツールバーからペン、直線、四角形、円、テキストを選択
2. **フリーハンド描画**: ペンツールで自由に描画（自動で図形認識）
3. **グリッド直線描画**: 直線ツールで正確な図形を描画（自動でグリッドにスナップ）
4. **水平・垂直線**: 直線ツール + Shiftキーで完全に水平・垂直な線
5. **テキスト入力**: テキストツールでクリックして文字を入力
6. **スタイル調整**: 線の太さ、色、フォントサイズを調整
7. **操作**: クリア、アンドゥ、リドゥで描画を管理

## テキスト機能

- **横書きテキスト**: 🔤ボタンで一般的な横書きテキスト
- **縦書きテキスト**: 📝ボタンで日本語の縦書きテキスト
- **フォントサイズ**: スライダーで12px〜48pxまで調整可能
- **入力方法**: テキストツール選択後、キャンバスをクリックして入力
- **確定**: Ctrl+Enterまたはテキストボックス外をクリック
- **キャンセル**: Escapeキーで入力をキャンセル

## グリッド機能

- **自動スナップ**: 直線・四角形・円ツールは自動的にグリッドにスナップ
- **20px間隔**: 細かい位置調整に便利
- **100px間隔**: 大きな区画の配置に便利
- **表示切り替え**: ⊞ボタンでグリッドのON/OFF

## キーボードショートカット

- **Shift + 直線ツール**: 水平・垂直線を描画
- **Shift + ペンツール**: フリーハンドでもグリッドにスナップ

## 図形認識機能

フリーハンドで描画した線は自動的に以下の図形に変換されます：

- **直線**: まっすぐな線として認識
- **円**: 閉じた曲線として認識  
- **四角形**: 4つの角を持つ図形として認識

## デプロイ

### GitHub Pages（自動デプロイ）

このプロジェクトはGitHub Actionsを使用してGitHub Pagesに自動デプロイされます。

1. **GitHubにプッシュ**: mainブランチにプッシュすると自動でビルド・デプロイ
2. **GitHub Pages設定**: リポジトリ設定 → Pages → Source: GitHub Actions
3. **アクセス**: `https://yourusername.github.io/heimenzukei/`

### 手動デプロイ

他のホスティングサービスを使用する場合：

```bash
# ビルド
npm run build

# distフォルダの内容をホスティングサービスにアップロード
```

**対応ホスティング:**
- **Netlify**: ドラッグ&ドロップで即座にデプロイ
- **Vercel**: GitHub連携で自動デプロイ
- **Firebase Hosting**: `firebase deploy`でデプロイ
- **Surge.sh**: `surge dist/`でデプロイ

### PWAとしてインストール

デプロイ後、ユーザーは以下の方法でアプリをインストールできます：

**iPad/iPhone:**
1. Safariでサイトにアクセス
2. 共有ボタン（📤）をタップ
3. 「ホーム画面に追加」を選択

**Android:**
1. Chromeでサイトにアクセス
2. 「ホーム画面に追加」プロンプトが表示
3. 「追加」をタップ

**デスクトップ:**
1. Chrome/Edgeでサイトにアクセス
2. アドレスバーの「インストール」アイコンをクリック
